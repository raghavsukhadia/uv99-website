# fonts

Self-hosted **Inter** and **Montserrat** (variable woff2, latin + latin-ext), declared
in `assets/css/fonts.css`. They replace the old Google Fonts `@import` in
`assets/css/styles.css` / `<link>` in the pages, which was a render-blocking request to a
third-party origin. Licence: SIL OFL 1.1 (`LICENSE.txt`).

The QR pages still use Google Fonts for Unbounded, Manrope and JetBrains Mono.
